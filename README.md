## 자동차 경주 게임 입출력 클래스

- 경주할 자동차의 이름을 입력 받기 전, 입력에 대한 설명을 출력한다.
  - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)\n`


- 경주할 자동차의 이름을 입력받는다.
   - 경주할 자동차 이름은 공백을 포함하지 않은 5글자 이하만 가능하다.
   - 모든 자동차 이름은 한 줄에 한 번에 입력된다.
   - 입력은 쉼표(`,`)로 구분한다.
   - 모든 입력된 자동차 이름은 중복되지 않는다.
   - 2개에서 10개의 이름을 입력받는다.


- 실행할 횟수를 입력 받기 전, 입력에 대한 설명을 출력한다.
  - `시도할 횟수는 몇 회인가요?`


- 실행할 횟수를 입력받는다.
  - 횟수는 한 줄에 입력을 받으며 범위는 1 ~ 20 으로 한다.


- `실행 결과`를 출력한다.


- 차수별 실행 결과를 출력한다.
  - 게임 클래스에서 받은 정보를 바탕으로 차수별 실행 결과를 출력한다.
  - 한 줄에 참가자 한명씩 출력하며 참가자의 이름과 함께 앞으로 이동한 횟수만큼 `-`을 출력한다.


- 경주 결과를 출력한다.
  - `최종 우승자 : @@@` 형태로 출력한다.
  - 최종 우승자가 2명 이상인 경우에는 쉼표(`,`)로 구분한다.


## 자동차 경주 게임 컨트롤러 클래스

- 자동차 이름에 관한 설명을 출력하고 이름을 입력받는다.
  - 입력받은 자동차의 이름을 파싱하고 검증하며 잘못된 입력의 경우 `IllegalArgumentException`을 발생시킨다.
  - 파싱한 데이터를 모델로 넘겨준다.


- 실행 횟수에 관한 설명을 출력하고 실행 횟수를 입력받는다.
  - 입력받은 실행 횟수를 검증하며 잘못된 입력의 경우 `IllegalArgumentException`을 발생시킨다.
  - 입력받은 실행 횟수만큼 모델에게 경주를 진행시킨다.


- 경주의 실행 결과를 출력한다.
  - 첫 번째 차수의 출력인 경우 결과 출력 전에 `실행 결과`를 출력한다.


- 최종 우승자를 출력한다.

## 자동차 경주 게임 모델 클래스

- 경주를 진행시킨다.
  - 각 참가자에 대한 이동 여부를 판단하고 진행 상황을 저장한다.


- 각 차수마다 참가자의 이동 여부를 판단한다.
  - 주어진 랜덤함수를 활용하여 0 ~ 9의 무작위 수를 구하고, 무작위 값이 4 이상인 경우 전진한다.


- 우승자를 판단한다.
  - 기존의 결과를 바탕으로 최종 우승자를 판단하여 컨트롤러에게 넘겨준다.
